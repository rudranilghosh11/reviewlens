# Review Lens Design System

Use the supplied Lamborghini-inspired visual language without Lamborghini logos, automotive imagery, or automotive content.

- Absolute black background: `#000000`.
- White primary typography: `#FFFFFF`.
- Primary gold action: `#FFC000`, with black text.
- Charcoal surfaces: `#202020`; secondary surface: `#181818`.
- Sharp rectangular buttons and panels; avoid pill-shaped controls and rounded dashboard cards.
- Oversized uppercase display headings, condensed/neo-grotesque typography, restrained uppercase labels.
- Generous whitespace and strong editorial hierarchy.
- Minimal borders, no decorative gradients/glows, restrained hover/focus states.
- Responsive layouts; preserve readable body copy, chart labels, tables, and controls.
- Gold is reserved for primary actions and meaningful emphasis; use muted grey for secondary text.
- Use accessible contrast and visible keyboard focus.
